# Asian Option Pricing Project

This project implements multiple methods for pricing Asian options under the Black–Scholes framework.

---

## Overview

We study the pricing of Asian options, focusing on the difference between:

- **Geometric average Asian options** (closed-form solution exists)
- **Arithmetic average Asian options** (no closed-form)

Implemented methods:

1. Geometric Asian (closed-form and monte carlo)
2. Arithmetic Asian (Monte Carlo)
3. Turnbull–Wakeman approximation
4. Levy approximation
